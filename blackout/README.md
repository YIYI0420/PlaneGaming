# 断电之后 · AFTER THE BLACKOUT

手机优先、电脑兼容的单人 3D 僵尸 FPS 试玩。使用本地随附的 Three.js r180，无运行时 CDN、模型或字体下载。

游玩：https://yiyi0420.github.io/PlaneGaming/blackout/

## 内容

- 三张独立地图：公交总站、雨夜货运码头、熔核供电站；每关三波，逐步增加奔袭者和护甲敌人。可直接选关，或成功撤离后连续进入下一关。
- 自选 M4A1、AK-47 或 AWM 主武器，另配无限备用弹药手枪。主武器弹药有限，可拾取补给。
- 红点、四倍、八倍镜；开镜改变实际视野并同步降低转向灵敏度。可在整备、暂停或 HUD 中更换。
- 第一波后前往配电箱，选择电网或炮台；第二波后选择穿透弹、快速装填或电击手雷。
- 第三波后击败最终首领，再启动北侧闸门，在 18 秒开门进攻中生存，然后实际进入绿色区域完成撤离。
- 本地结算、配置和纪录保存；合成音效，有限尸体、粒子与同时活动敌人数。

## 操作

手机建议横屏。左侧摇杆移动，右侧空白处滑动转向。默认对准敌人自动射击，也可按住射击键；支持 ⇧ 奔跑、独立跳跃、开镜、换弹、切枪、手雷和接近设备交互。页面失焦、进入后台或改变屏幕方向会暂停。

电脑：WASD 移动，Shift 奔跑，空格跳跃，鼠标转向，左键射击，右键按住或 Q 切换开镜，R 换弹，1/2/3 切换主武器、手枪、近战，V 持刀，G 手雷，E 交互，P 暂停/继续，Esc 暂停。浏览器不支持锁定鼠标时可按住画面拖动转向。

## 本地运行

本游戏使用 JavaScript ES 模块，需要 HTTP 服务。不能直接双击 HTML 文件。

在仓库根目录执行：

```sh
python -m http.server 8767
```

访问 `http://localhost:8767/blackout/`。需要支持 WebGL 2 的浏览器。手机画质默认省电模式，其他设备可自行切换。手机帧率、发热和触屏手感仍需在目标真机上测试。

## 验证与结构

`node tests/blackout-smoke.cjs` 检查枪械/倍率、弹药、爆头与护甲、遮挡、穿透、手雷、设施、寻路、暂停、失败和 18 种配置的完整阶段流程。阶段模拟使用测试生命值，不能代表玩家生存难度测试。

- `SPEC.md`：详细规则与初始数值。
- `engine.js`：独立逻辑、命中检测、寻路、状态与结算。
- `scene.js`：Three.js 场景、枪模、敌人、动画与特效。
- `game.js`：输入、HUD、配置保存与 Web Audio。
- `vendor/`：Three.js 0.180.0 与 MIT 许可证。

这是原创低多边形试玩，不包含联网对战、账号服务器或独立手游安装包。

## V0.2 操作与画面更新

修复右键按住后左键射击、两键分别松开和失焦后的按键状态。红点镜框、屏幕红点与实际命中射线统一居中。增加跳跃、低矮掩体落地及走下掩体后的重力判定。

画质提供省电／标准／高清三档，高清增加动态阴影、更高分辨率；基础画面加入抗锯齿、PBR 材质、环境反射、地面与布料纹理、渐变天空和枪械细节。桌面默认高清，手机默认省电；整备与暂停菜单均可切换。

回归检查：`node tests/blackout-controls.cjs`、`node tests/blackout-presentation.mjs`、`node tests/blackout-jump.cjs`，另保留原始完整流程模拟。

## V0.3 奔跑、近战和最终首领

Shift + 移动方向奔跑，速度 6.4 米/秒（步行 3.8），体力 100、每秒消耗 20，停跑 0.8 秒后每秒恢复 24。耗尽后至少恢复到 25 才可再跑；开火和开镜会停止奔跑。手机 ⇧ 按钮切换奔跑。

每局在军用匕首、爪刀、开山刀、武士刀、战斧中选一种，主武器与手枪继续保留。按 3/V 持刀，左键或手机射击键轻击，右键/F 或持刀时手机开镜键重击，手机 ⇄ 循环三种武器。不同近战拥有独立模型、攻速、距离和目标数量，背刺及战斧破甲会影响伤害。

三波后迎战约 3.8 米高、9600 血的守门者：冲撞锁定方向后突进，震地有圆圈与抬手预警（可跳过），毒液先标记地面后产生持续伤害；三阶段护甲与弱点窗口，后续增加连环冲撞、冲击波及随从，最后阶段狂暴。战前恢复 40 生命、补满主武器备用弹药、刷新补给、补一枚手雷。击败后再进行开闸撤离。首领训练可直接挑战，独立结算并排除在完整撤离纪录外。

`node tests/blackout-expansion.cjs` 验证奔跑与体力、五种近战差异、遮挡、首领预警和技能命中/躲避、狂暴、死亡清理及训练/主线分流。完整流程模拟更新为三波 42 个普通/特殊敌人加一个最终首领。

## V0.4 独立刀法与三阶段首领

五种近战各有轻重击、不同握法、手腕轨迹、双手配合与连段。伤害在刀刃接触时检查实时距离/遮挡；收势不可切枪取消。重击消耗 18 体力，累积破势可打断首领。首领战增加护甲、技能后的弱点、撞墙硬直、阶段变化与弹药补给，详细数值见 SPEC。

`node tests/blackout-melee-v4.mjs` 检查十套动画连续性、动作/伤害时机、破势与阶段机制，并输出三枪理想命中模型；该模型不代表实际玩家战斗时长。

## V0.5 三关战役

| 关卡 | 布局与节奏 | 三波敌人数 | 区域首领 | 开门防守 |
|---|---|---|---|---|
| 01 公交总站 | 公交通道与停车区 | 8 / 15 / 19 | 守门者 · 9600 血 | 18 秒 |
| 02 雨夜货运码头 | 冷色雨夜、集装箱绕行、更多奔袭者 | 12 / 19 / 24 | 潮噬者 · 10800 血，偏重冲撞和毒液 | 21 秒 |
| 03 熔核供电站 | 变压器与反应堆、开阔交叉火线、更多护甲 | 14 / 23 / 29 | 熔核暴君 · 13200 血，第一阶段起产生震地冲击波 | 24 秒 |

每关保留设施二选一、强化三选一及首领后的撤离。撤离结算可继续下一关；转场保留主武器、倍率和刀具，恢复生命、弹药与手雷，重新选择本关设施与强化。可重试当前关卡；连续三关成功后显示总用时与总击杀。离开页面后可在整备界面重新选关，未完成关内战斗不存档。

各关有独立障碍、补给、配电箱、设施位置、出怪入口和小地图。纪录按关卡比较，旧版纪录归入第一关，首领训练仍单独结算。地图首次选择时构建并缓存，最多三份场景，切图不新建 WebGL 上下文。

`node tests/blackout-levels.cjs` 检查关卡配置、目标通路、首领参数与下一关规则，并模拟 54 种枪械/设施/强化/关卡组合的完整流程。该模拟提高测试生命值以隔离流程，不代表真实生存难度或手机性能。
