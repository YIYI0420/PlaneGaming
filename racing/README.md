# 极速边界 · NEON APEX

原创伪 3D 街机赛车，直接用浏览器打开 `index.html` 即可游玩，无依赖、无外部素材、无需联网。

## 游玩

- WASD / 方向键：转向、加速、刹车。默认启用辅助油门，可在车库关闭。
- 空格 + 转向：漂移。松开漂移后把集气转为氮气。
- Shift：消耗氮气加速。
- P / Esc：暂停或继续。切换窗口时自动暂停。
- R：回到赛道中央，损失部分速度。
- 手机：按住转向、漂移、氮气和刹车按钮，横屏体验更佳。

## 功能

- 4 款车辆，各有不同的极速、加速、操控和抓地力。
- 6 种车身颜色、5 种涂装、3 种轮毂，车库实时外观预览。
- 引擎、涡轮和轮胎各 3 档调校，实际影响驾驶物理。
- 蔚蓝海岸、霓虹都市、赤岩峡谷、极地山脊 4 张循环赛道，独立曲率、起伏和景物。
- 6 人 AI 竞速赛、单人计时挑战；3 档难度、1～3 圈、晴雨雪天气可选。
- 漂移集气、氮气加速、碰撞减速、驶出路面减速、赛道救援。
- 小地图、排名、实时速度、圈速、完赛结算、本地配置和纪录保存。
- 程序合成引擎、漂移和倒计时音效，默认关闭。

这是独立原创游戏，不包含 QQ 飞车官方素材或账号系统，不含在线联机。纪录只保存在当前浏览器，不同地图、模式、圈数、难度和天气单独比较；保留最近 80 场记录。

## 发布

仓库使用 GitHub Pages 的 `main` 分支根目录发布，本游戏入口为 `/PlaneGaming/racing/`；仓库根目录继续提供飞机大战。

## 检查

在仓库工作区运行 `node tests/racing-smoke.cjs`，验证驾驶物理、16 组完整双圈比赛、各地图和涂装的渲染坐标。
