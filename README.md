# 银河防线 · 飞机大战

使用原生 HTML、CSS 和 JavaScript 编写的太空街机游戏。

## 操作

- WASD / 方向键移动，也支持鼠标跟随和触屏拖动。
- 自动射击；X 或脉冲按钮清屏。
- P / Esc 暂停与继续，Enter 开始或重开。
- 音符按钮开启或关闭音效。

包含武器升级、护盾、修复补给、Boss 战与浏览器本地最高分。

## 本地运行

直接打开 `index.html`，无需安装依赖。

## GitHub Pages

在仓库 Settings → Pages 中选择 Deploy from a branch，然后选择 `main` 分支和 `/ (root)`，保存后等待 GitHub 发布完成。
